# PatchFarm

**Open-source patches for real problems.**

Plugins, mini apps, skills and AI agents that fix everyday problems in development, design and business. Free to copy, run and change.

## What grows here

| | What it is | Who it's for |
|---|---|---|
| 🧩 **Plugins** | Extensions that add missing features to tools you already use | Developers, designers, teams |
| 📱 **Mini apps** | Small, focused apps that do one job well | Small businesses, freelancers, makers |
| 🧠 **Skills** | Ready-made instruction packs that teach AI assistants a workflow | Anyone working with AI assistants |
| 🤖 **AI agents** | Complete agents you clone and run on your own machine | Builders who want automation they control |

## How every project works

- **Copy and run.** Clone it, follow a short README, and it works. No sign-up, no hosted service in the way.
- **One real problem.** Each repo starts from a specific pain point and says up top what it fixes.
- **Yours to change.** Open-source licenses, readable code, no lock-in.
